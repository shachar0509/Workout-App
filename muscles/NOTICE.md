# Muscle images

Generated by `tools/gen_muscle_svgs.py` from the body model (polygon data) of
[react-body-highlighter](https://github.com/GV79/react-body-highlighter), MIT License, (c) 2020 GV79.
The model has no separate lats / serratus anterior / levator scapulae, so the nearest region is highlighted.
`cardiovascular-system.svg` is a simple heart in the same colours (cardio is not a muscle).
